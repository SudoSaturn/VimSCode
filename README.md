# nvim-vscode

my neovim config, set up to feel a lot like VS Code.

it has the VS Code dark look, file explorer, tabs, search, terminal, git tools,
autocomplete, debugging, and familiar shortcuts.

## install

back up your old neovim config, then run:

```sh
git clone https://github.com/SudoSaturn/nvim-vscode ~/.config/nvim
nvim
```

plugins install automatically the first time.

use `:Lazy` for plugins, `:Mason` for language tools, and `Ctrl+Shift+P` for the
command palette.
